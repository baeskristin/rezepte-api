# 🍳 Recipe API

Simple REST API for managing recipes and their ingredients.

## 🚀 Features

- ✅ Create, view, and delete recipes
- ✅ Create and manage ingredients
- ✅ Assign ingredients to recipes
- ✅ PostgreSQL database
- ✅ Docker setup for local development
- ✅ Swagger API documentation

## 🛠️ Tech Stack

- Node.js
- Express
- TypeScript
- PostgreSQL
- Docker & Docker Compose

## 📦 Getting Started

### Start the database

```bash
docker compose up -d
```

### Install dependencies

```bash
npm install
```

### Run the application

```bash
npm run dev
```
